# SQL scripts

These SQL files are a GitHub-ready reconstruction of the Oracle database
implementation described in the original university project report.

The original `.sql` source files are no longer available. Therefore:
- the schema and constraints are reconstructed from the report;
- sequence names/definitions are reconstructed where the report only
  describes their use;
- credentials are intentionally not included;
- security grants are a practical reconstruction of the documented roles.

Target DBMS: Oracle Database.
